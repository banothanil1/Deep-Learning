3. PERCEPTRON (ARTIFICIAL NEURON)

- It is a single-layered neural network and a binary classifier.
- Building blocks: input layer, hidden layer, weights, activation function.

Step 1: Weighted sum
Z = w1*x1 + w2*x2 + ... + wn*xn + b
or Z = sum of (xi * wi) + b

- x = inputs
- w = weights (importance of each input)
- b = bias (shifts the decision boundary)

Step 2: Activation function
y_hat = Act(Z)
It transforms the output into 0 to 1 or -1 to 1.

Example dataset (Pass/Fail):
x1 (IQ)   x2 (Study hours)   Output
95        3                  0
110       4                  1
100       5                  1

Loss (error): the difference between actual and predicted output.
Example: y = 1, y_hat = 0, so error = 1 - 0 = 1

Activation functions:
- Step function: threshold = 0
  Output 1 if Z > 0, else 0
- Sigmoid function: threshold = 0.5
  Output 1 if Z > 0.5, else 0 (smooth curve between 0 and 1)

Link with linear regression:
- y = mx + c
- y = b0 + b1*x1 + b2*x2 + ... + bn*xn

The perceptron solves a linear problem, so a perceptron is a linear classifier.


4. PERCEPTRON MODELS

A. Single Layer Perceptron
- A feed forward neural network (data flows only forward).
- Flow: inputs -> Z = sum(xi*wi) + b -> Act(Z) with threshold -> y_hat (1 or 0)
- Works only on linearly separable problems.

B. Multi Layered Perceptron (ANN)
Key concepts to learn:
1. Forward propagation
2. Backward propagation
3. Loss functions
4. Activation functions
5. Optimizers

Linearly separable:
- One straight line separates the two classes.
- Solved by a single layer perceptron.

Non-linearly separable:
- Classes are mixed, so no single line works.
- Solved by a multi-layered neural network.

1. ANN INTUITION
------------------------------------------------------------------
An Artificial Neural Network is a stack of simple units (neurons)
that learns a mapping from inputs to outputs by adjusting its
parameters.

Single neuron:
  z = w1*x1 + w2*x2 + ... + wn*xn + b
  a = f(z)    (f = activation function)

  - Weights (w): control how much each input matters.
  - Bias (b): shifts the activation, like an intercept.
  - Activation f(z): adds non-linearity. Without it, many layers
    collapse into one linear function.

Structure:
  - Input layer   : takes the features.
  - Hidden layers : learn intermediate representations (more layers
                    = more abstract features).
  - Output layer  : gives the prediction.

Common activation functions:
  Sigmoid : 1 / (1 + e^-z)          | derivative: a(1 - a)
            Use: binary output
  Tanh    : (e^z - e^-z)/(e^z + e^-z) | derivative: 1 - a^2
            Use: hidden layers (older)
  ReLU    : max(0, z)               | derivative: 1 if z>0 else 0
            Use: default for hidden layers
  Softmax : e^zi / sum(e^zj)
            Use: multi-class output


2. HOW LEARNING HAPPENS
------------------------------------------------------------------
Learning = finding the weights and biases that minimize the loss.

Steps:
  1. Forward propagation : inputs flow through layers to give y_hat.
  2. Loss calculation    : measure error between y_hat and y.
  3. Backpropagation     : compute gradient of loss w.r.t. every weight.
  4. Weight updation     : move weights in the direction that reduces loss.
  5. Repeat for many epochs.

Loss functions:
  - Regression (MSE)       : L = (1/n) * sum( (y - y_hat)^2 )
  - Binary classification  : L = -[ y*log(y_hat) + (1-y)*log(1-y_hat) ]
  - Multi-class (CCE)      : L = -sum( yi * log(y_hat_i) )

  Loss = error on one sample.
  Cost = average loss over the whole dataset.

1. THE DIFFERENCE
------------------------------------------------------------------
  Forward pass : data travels input layer -> hidden -> output layer
                 (gives the prediction)

  Backward pass: error travels output layer -> hidden -> input layer
                 (gives the gradients)

  Iteration    : one batch does forward + loss + backward + ONE
                 weight update

  Epoch        : all batches of the dataset done once
                 (many iterations)


2. EXAMPLE
------------------------------------------------------------------
  Dataset = 1000 samples, batch size = 100

  Iteration 1  : batch 1 (samples 1-100)     -> forward, backward, update
  Iteration 2  : batch 2 (samples 101-200)   -> forward, backward, update
  Iteration 3  : batch 3 (samples 201-300)   -> forward, backward, update
  ...
  Iteration 10 : batch 10 (samples 901-1000) -> forward, backward, update

  After these 10 iterations, all 1000 samples have been used once.
  That is ONE EPOCH.

  Epoch 1 -> 10 iterations -> 10 weight updates
  Epoch 2 -> the data is shuffled and the same 10 iterations repeat
  ...


3. VISUAL
------------------------------------------------------------------
  EPOCH 1
  +-----------------------------------------------------------+
  | batch 1: input -> output -> loss -> backprop -> update    |
  | batch 2: input -> output -> loss -> backprop -> update    |
  | batch 3: input -> output -> loss -> backprop -> update    |
  | ...                                                       |
  | batch 10: input -> output -> loss -> backprop -> update   |
  +-----------------------------------------------------------+
  EPOCH 2
  +-----------------------------------------------------------+
  | (same again, so the weights keep improving)               |
  +-----------------------------------------------------------+


4. SPECIAL CASE
------------------------------------------------------------------
  If batch size = whole dataset (Batch GD), then one iteration
  covers all the data, so 1 iteration = 1 epoch.
  Only in that case does "one forward pass + one update" equal
  one epoch.

3. BACKPROPAGATION
------------------------------------------------------------------
Backprop = chain rule of calculus applied layer by layer, from the
output back to the input. It tells us how much each weight
contributed to the error.

Chain rule for a weight in the last layer:
  dL/dw = dL/da * da/dz * dz/dw

  - dL/da : how the loss changes with the neuron's output
  - da/dz : derivative of the activation function
  - dz/dw : the input feeding that weight (z = wx + b, so this is x)

For a deeper network (weight w1 in layer 1 of a 2-layer net):
  dL/dw1 = dL/dy_hat * dy_hat/dz2 * dz2/da1 * da1/dz1 * dz1/dw1

The gradient of an earlier layer reuses gradients already computed
for later layers, which is why backprop is efficient. Errors are
propagated backward through the same weights used in the forward pass.

Vanishing and exploding gradients:
  Many derivatives get multiplied together.
  - If derivatives < 1 (sigmoid/tanh saturate), gradients shrink
    toward 0 in early layers -> VANISHING GRADIENT (early layers
    stop learning).
  - If derivatives > 1, gradients blow up -> EXPLODING GRADIENT
    (unstable training).

  Fixes: ReLU / Leaky ReLU, proper weight initialization
  (Xavier for tanh/sigmoid, He for ReLU), batch normalization,
  gradient clipping, residual connections.


4. WEIGHT UPDATION (GRADIENT DESCENT)
------------------------------------------------------------------
Update rule:
  w_new = w_old - lr * dL/dw
  b_new = b_old - lr * dL/db

  - lr (learning rate, eta) = step size.
  - The gradient points toward steepest INCREASE of loss, so we
    move in the opposite direction.

Effect of learning rate:
  - Too small : slow convergence, may get stuck.
  - Too large : overshoots, oscillates, or diverges.
  - Just right: smooth convergence to a minimum.

Gradient descent variants:
  Batch GD
    Data per update : whole dataset
    Pros : stable, smooth
    Cons : slow, memory heavy

  Stochastic GD (SGD)
    Data per update : 1 sample
    Pros : fast updates, can escape local minima
    Cons : noisy

  Mini-batch GD
    Data per update : n samples (e.g. 32, 64)
    Pros : best balance, GPU friendly
    Cons : needs batch size tuning

Optimizers (improvements over plain GD):
  - Momentum : adds a velocity term, smooths updates.
  - AdaGrad  : adaptive learning rate per parameter (decays too
               aggressively).
  - RMSprop  : fixes AdaGrad using moving average of squared gradients.
  - Adam     : Momentum + RMSprop. Usual default choice.


5. WORKED EXAMPLE (SINGLE NEURON)
------------------------------------------------------------------
Given: x = 0.5, y = 1, w = 0.4, b = 0, lr = 0.1
       sigmoid activation, loss L = 0.5 * (y - a)^2

Forward pass:
  z = 0.4*0.5 + 0 = 0.2
  a = sigmoid(0.2) = 0.5498
  L = 0.5 * (1 - 0.5498)^2 = 0.1013

Backward pass: 
  dL/da = -(y - a)       = -0.4502
  da/dz = a(1 - a)       = 0.5498 * 0.4502 = 0.2475
  dz/dw = x              = 0.5
  dL/dw = -0.4502 * 0.2475 * 0.5 = -0.0557
  dL/db = -0.4502 * 0.2475 * 1   = -0.1114

Update:
  w_new = 0.4 - 0.1 * (-0.0557) = 0.4056
  b_new = 0   - 0.1 * (-0.1114) = 0.0111

The weight increased slightly, pushing the output closer to the
target of 1. Repeating this over many iterations drives the loss down.


6. QUICK REVISION SUMMARY
------------------------------------------------------------------
- ANN = layers of neurons computing f( sum(w*x) + b ).
- Learning = minimizing loss by tuning weights and biases.
- Forward prop gives the prediction.
- Backprop gives the gradients using the chain rule.
- Weight update: w = w - lr * dL/dw
- Watch out for: vanishing/exploding gradients, bad learning rate,
  overfitting (use dropout, regularization, early stopping).
- Training loop: forward -> loss -> backward -> update -> repeat.

------------------------------------------------------------------
  FORWARD PROPAGATION  (compute prediction)

   x ---> [W1,b1] ---> z1 ---> a1 ---> [W2,b2] ---> z2 ---> y_hat ---> LOSS
                                                                         |
  BACKWARD PROPAGATION (compute gradients via chain rule)                |
                                                                         v
   dW1 <--- dz1 <--- da1 <--- dW2 <--- dz2 <--- dL/dy_hat <-------------+

  Then update:  W = W - lr * dW   for every layer.

G8. GRADIENT DESCENT ON A LOSS CURVE
------------------------------------------------------------------
  Loss
   |
   |  *                                    *
   |   *                                  *
   |    *                               *
   |     *  (start)                    *
   |      S                          *
   |       \                       *
   |        \                    *
   |         v                 *
   |          S              *
   |           \           *
   |            v        *
   |             S     *
   |              \  *

  Slope negative (left of min)  -> w increases
  Slope positive (right of min) -> w decreases
  w_new = w_old - lr * slope

VANISHING GRADIENT PROBLEM: DETAILED THEORY + LOSS vs WEIGHT GRAPH
==================================================================

1. BACKGROUND
------------------------------------------------------------------
Training a neural network is a loop:

    forward pass -> loss -> backpropagation -> weight update

Backpropagation finds the gradient of the loss with respect to every
weight (how steep the loss curve is at the current weight). Gradient
descent then moves each weight using that gradient:

    w_new = w_old - lr * dL/dw

The size of the update depends directly on the size of the gradient:
  - large gradient -> large change in the weight
  - gradient close to 0 -> almost no change in the weight

Everything in the vanishing gradient problem comes from this one
dependence.


2. DEFINITION
------------------------------------------------------------------
The vanishing gradient problem is the situation where, while the
error is propagated backward from the output layer to the input
layer, the gradients become smaller and smaller. By the time they
reach the early layers they are almost zero, so those layers get
practically no weight update and stop learning.

In one line:  gradient ~ 0  =>  w_new ~ w_old  =>  no learning.


3. WHY IT HAPPENS (CHAIN RULE)
------------------------------------------------------------------
The loss is connected to an early weight through many layers:

    w1 -> z1 -> a1 -> z2 -> a2 -> ... -> z_n -> a_n -> L

By the chain rule the gradient is a PRODUCT, with one factor for
every layer the error passes through:

    dL/dw1 = dL/da_n * [f'(z_n)*w_n] * [f'(z_(n-1))*w_(n-1)]
             * ... * [f'(z_2)*w_2] * f'(z_1) * x

If these factors are mostly smaller than 1, multiplying many of them
makes the result shrink exponentially as the number of layers grows:

    factor 0.25 per layer
    1 layer   : 0.25
    5 layers  : 0.00098
    10 layers : 0.00000095
    20 layers : 0.0000000000009

So the deeper the network, the smaller the gradient at the first
layers.


4. CAUSES
------------------------------------------------------------------
  1. Many layers
       More layers means more factors multiplied together.

  2. Small derivative values of the activation
       When the derivative f'(z) is small (below 1, and close to 0
       when the neuron is saturated), every layer shrinks the
       gradient a bit more.

  3. Small weights
       The weight w is also one of the factors. Weights initialized
       too small make each factor even smaller.

  4. Poor initialization
       Starting weights that are not scaled properly for the layer
       size make the factors consistently less than 1.


5. WHAT IT DOES TO LEARNING
------------------------------------------------------------------
  - Layers near the OUTPUT get large gradients, so they learn fast.
  - Layers near the INPUT get tiny gradients, so they barely move
    from their random starting values.
  - The early layers are the ones that detect the basic features of
    the raw input. If they do not learn, the later layers receive
    poor features, however well they learn themselves.
  - The loss falls a little at first, then gets stuck on a plateau
    at a high value.
  - Training becomes very slow and the final accuracy is poor.


6. HOW TO RECOGNIZE IT
------------------------------------------------------------------
  - Loss decreases extremely slowly or stays flat.
  - Gradient values of the first layers are close to 0 compared to
    the last layers.
  - Weights of the first layers hardly change between epochs.
  - Adding more layers makes the result worse instead of better.


7. WHERE IT APPEARS
------------------------------------------------------------------
  - Deep feed-forward networks.
  - Recurrent networks on long sequences: the gradient is multiplied
    at every time step, so the effect of early inputs fades and
    long-term dependencies cannot be learned.


8. FIXES (WHY EACH WORKS)
------------------------------------------------------------------
  - Better activation functions: keep the derivative from shrinking
    the product.
  - Proper weight initialization (Xavier / He): keeps the size of
    activations and gradients roughly constant across layers.
  - Batch normalization: keeps the inputs of each layer in a range
    where the slope does not go flat.
  - Residual (skip) connections: give the gradient a shortcut path
    straight back to the early layers.
  - LSTM / GRU for sequences: gates give the gradient a path that
    does not shrink over time steps.


9. GRAPH: LOSS vs WEIGHT (HEALTHY vs VANISHING GRADIENT)
------------------------------------------------------------------
X-axis = weight W, y-axis = loss L. The slope of the curve at the
current weight is the gradient. S0, S1, S2 ... are the weight
values after each update, G is the global minimum.

  Loss
   |
   |  S0
   |    \
   |      S1                       (a) healthy gradient:
   |        \                          steep slope, big steps,
   |          S2                       reaches G in a few updates
   |            \
   |              S3
   |                \_ S4 _ G
   |
   |  S0 S1 S2 S3 S4 S5 S6 ...     (b) vanishing gradient:
   |  _______________________          almost flat slope, tiny steps,
   |                         \         stays near S0 and never
   |                          \        reaches G
   |                           \_____ G
   +-------------------------------------------------> W

  (a) step = lr * (large slope)  -> big move each iteration
  (b) step = lr * (slope ~ 0)    -> almost no move each iteration

  Numbers with lr = 0.1 and start W = 0.50:
    healthy   slope = -4.0    -> step = +0.40 per update
    vanishing slope = -0.004  -> step = +0.0004 per update
  The vanishing case learns about 1000 times slower.


10. QUICK REVISION
------------------------------------------------------------------
  - Backprop multiplies one factor per layer (chain rule).
  - Factors below 1 multiplied many times shrink exponentially.
  - Early layers get gradient ~ 0, so w_new ~ w_old.
  - Flat slope on the loss vs weight graph = tiny steps = stuck.
  - Fixes: good initialization, batch normalization, residual
    connections, LSTM/GRU for sequences.
